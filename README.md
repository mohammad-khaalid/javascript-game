# 🎮 Catch The Box

A simple and fun browser game built using **HTML**, **CSS**, and **Vanilla JavaScript**.

The objective is simple: **click the moving red box as many times as possible before the timer runs out!**

---

## 🚀 Demo

Open the `index.html` file in your favorite web browser to start playing.

## ✨ Features

* 🎯 Click the moving box to earn points
* ⏱️ 30-second countdown timer
* 📈 Real-time score tracking
* 🎲 Random box movement
* 🔄 Restart button
* 💻 Single HTML file (no dependencies)
* ⚡ Lightweight and beginner-friendly

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/catch-the-box.git
```

2. Open the project folder.

3. Double-click **index.html** or open it in your browser.

No installation or build process is required.

---

## 🎮 How to Play

1. Click the red box whenever it appears.
2. Each successful click increases your score.
3. The box changes its position every second.
4. Try to score as many points as possible before the timer reaches zero.
5. Click **Restart Game** to play again.
